# Skill: sil-sync

**Назначение:** Получить одобренные куратором улучшения из базового GitHub-репо и применить их локально — с security scan и поштучным апрувом каждого изменения.
**Когда использовать:** Периодически для получения улучшений от других пользователей. Напоминается при старте сессии если прошло > 14 дней с последнего sync. Также после того как куратор сообщил о новых мержах.
**Требования:** `gh` CLI установлен и авторизован, `git` установлен.

---

## PROCESS

### Шаг 1 — Проверь состояние

1. Прочитай `~/.claude/skills/sync-state.json`:
   - Если файл не существует — создай из шаблона, сообщи пользователю, продолжай
   - Извлеки `base_repo` и `last_sync`

2. Если `base_repo` пуст:
   ```
   Укажи URL базового репо (например: https://github.com/username/sil-base):
   ```
   Дождись ответа, сохрани в `sync-state.json`.

3. Проверь `gh` CLI:
   ```bash
   gh --version
   ```
   Если не найден — покажи инструкцию установки, остановись.

4. Сообщи:
   ```
   Последний sync: [last_sync или "никогда"]
   Получаю обновления из [base_repo]...
   ```

---

### Шаг 2 — Pull из base repo

```bash
CACHE_DIR="$HOME/.claude/.sil-base-cache"
BASE_REPO="[base_repo]"

if [ -d "$CACHE_DIR/.git" ]; then
  cd "$CACHE_DIR" && git fetch origin && git reset --hard origin/main
else
  gh repo clone "$BASE_REPO" "$CACHE_DIR"
fi
```

---

### Шаг 2.5 — Security scan (ОБЯЗАТЕЛЬНО перед показом дифов)

Прочитай `~/.claude/skills/sil-security-scan/patterns.md` и применяй все паттерны
к КАЖДОМУ файлу из base repo, который отличается от локальной версии.

**Сканируй:**
- Все `SKILL.md` файлы из base которые изменились
- Новые записи в `hard-problems.md`
- Новые записи в `best-practices.md`

**Результат для каждого файла:**
- Чисто → файл попадает в очередь дифов
- Подозрительное → файл БЛОКИРУЕТСЯ:

```
⛔ SECURITY SCAN: подозрительный контент

Файл:     [filename]
Категория: [название]
Паттерн:  [паттерн]
Строка:   "[цитата]"

Этот файл пропущен. Проверь PR вручную: [base_repo]/pulls
```

После скана — сообщи итог:
```
Security scan завершён:
  Чистых файлов: N (войдут в очередь)
  Заблокировано: M (пропущены)
```

---

### Шаг 3 — Сравни с локальными версиями

Для каждого чистого файла из base:

**SKILL.md файлы:**
- Сравни `~/.claude/skills/[name]/SKILL.md` с версией из cache
- Если файла нет локально → это новый скилл
- Если содержимое отличается → это обновление

**hard-problems.md:**
- Найди записи `## [YYYY-MM-DD]` которых нет локально
- Группируй как одно изменение

**best-practices.md:**
- Аналогично

Если нет ничего нового:
```
Нет новых обновлений из base repo с [last_sync].
```
Переходи к Шагу 6 (обнови last_sync).

---

### Шаг 4 — Покажи дифы и апрувь

Тот же паттерн что в `improve` — по одному изменению:

```
── Обновление N/Total: [тип] ──────────────────
[тип: "Новый скилл" / "Обновление скилла" / "hard-problems" / "best-practices"]

ДОБАВЛЯЕТСЯ / ИЗМЕНЯЕТСЯ:
[контент или diff]

Источник: [base_repo] (прошло куратора)
Применить? (да / нет / пропустить все оставшиеся)
```

Варианты ответа:
- `да` / `apply` → применяй
- `нет` / `пропусти` → пропускай, переходи к следующему
- `пропустить все` → завершай с текущими результатами

---

### Шаг 5 — Применяй подтверждённые изменения

**SKILL.md обновления:**
- Скопируй файл из cache в `~/.claude/skills/[name]/SKILL.md`

**Новые скиллы:**
- Скопируй всю директорию `~/.claude/skills/[name]/`
- Добавь строку в `~/.claude/skills/index.md` (в нужную группу):
  ```
  | `[name]` | [из описания в SKILL.md] | [теги] | 0 | ✅ Ready |
  ```
- Сообщи: `✓ Новый скилл [name] установлен`

**hard-problems / best-practices:**
- Аппенд новых записей в конец локального файла
- Сообщи: `✓ Добавлено N новых записей в [filename]`

---

### Шаг 6 — Обнови sync-state.json

```json
{
  "last_sync": "YYYY-MM-DD"
}
```
(остальные поля без изменений)

Финальный отчёт:
```
── Итог sil-sync ───────────────────────────────

Применено:      N изменений
Пропущено:      M (вручную / заблокировано security scan)
Новые скиллы:   [список или —]

✓ sync-state.json обновлён (last_sync: YYYY-MM-DD)

Следующий sync рекомендован через 14 дней.
```
