# Skill: Sales Guide

**Назначение:** Онбординг и создание продуктовых / портфельных гайдов из документов (docx, PDF, сайт). Фиксированный чеклист вопросов при старте, шаблон карточки вендора/продукта, финальный вывод в HTML/PDF.
**Когда использовать:** Когда пользователь хочет сделать Sales Guide, Product Guide, Partner Catalog, или аналогичный структурированный документ на основе исходных материалов.
**Результат:** Структурированный HTML/PDF гайд с карточками вендоров/продуктов, брендированным оформлением и контактной информацией.

---

## PROCESS

### Шаг 1 — Онбординг: чеклист вопросов

Задай все вопросы ниже **одним сообщением** до начала работы.
Не пропускай вопросы — они определяют весь дальнейший дизайн документа.

```
Прежде чем начать, уточню несколько вещей:

1. АУДИТОРИЯ
   Кто читатель? (ИТ-директор / менеджер по закупкам / технический специалист / продавец)
   Знакомы ли они с темой или нужно объяснять базу?

2. ГЛУБИНА
   Что важно для аудитории? (отметь нужное)
   [ ] Боли и проблемы, которые решает продукт
   [ ] Профиль ЛПР (кто принимает решение о покупке)
   [ ] Регуляторика и compliance
   [ ] Технические характеристики
   [ ] Конкурентное сравнение

3. SCOPE ВЕНДОРОВ / ПРОДУКТОВ
   Какие вендоры/продукты включить?
   Есть ли источники: docx, PDF, URL сайта?
   Нужно ли дополнить из открытых источников (сайты вендоров)?

4. БРЕНДИНГ
   Есть ли фирменные цвета (hex), логотип, шрифты?
   Если нет — использовать нейтральный корпоративный стиль?

5. ФОРМАТ ВЫВОДА
   [ ] HTML (для просмотра в браузере)
   [ ] PDF через Ctrl+P / @media print
   [ ] Оба варианта
   Ориентация: A4 вертикально / горизонтально?

6. КОНТАКТЫ
   Чьи контакты поставить в конце / на карточках?
   (имя, email, телефон, должность)
```

Дождись ответов. Не угадывай.

### Шаг 2 — Сбор материалов

На основе ответов из Шага 1:

1. **Документы** → прочитай предоставленные файлы (docx/PDF)
2. **Сайты** → если указаны URL или нужно дополнить — используй `web-scraper`
3. **Брендинг** → если есть PDF с логотипом — используй `extract-brand-palette`

Составь список вендоров/продуктов с полями:
- Название, категория, ключевые возможности
- Боли которые решает (если запрошено)
- ЛПР профиль (если запрошено)
- Сертификаты/compliance (если запрошено)

### Шаг 3 — Структура документа

Предложи структуру перед генерацией:

```
Предлагаемая структура гайда:

1. Обложка (название, компания, дата)
2. Введение (1 абзац — для кого и о чём)
3. Карточки вендоров/продуктов (N штук)
4. Сводная таблица сравнения (опционально)
5. Контакты

Подтвердить или изменить?
```

Дождись подтверждения.

### Шаг 4 — Генерация HTML

**Шаблон карточки вендора:**

```html
<div class="vendor-card">
  <div class="vendor-header">
    <div class="vendor-logo">[LOGO или аббревиатура]</div>
    <div class="vendor-meta">
      <h2 class="vendor-name">[Название]</h2>
      <span class="vendor-category">[Категория]</span>
    </div>
  </div>

  <div class="vendor-body">
    <div class="vendor-description">[Краткое описание — 2-3 предложения]</div>

    <div class="pain-list">
      <h3>Решаемые задачи</h3>
      <ul>
        <li>[боль 1]</li>
        <li>[боль 2]</li>
        <li>[боль 3]</li>
      </ul>
    </div>

    <div class="vendor-table">
      <table>
        <tr><td>Ключевые продукты</td><td>[список]</td></tr>
        <tr><td>Целевой заказчик</td><td>[профиль ЛПР]</td></tr>
        <tr><td>Сертификаты</td><td>[ФСТЭК / ФСБ / ISO и др.]</td></tr>
        <tr><td>Сайт</td><td><a href="[url]">[домен]</a></td></tr>
      </table>
    </div>
  </div>
</div>
```

**CSS переменные (брендинг):**
```css
:root {
  --brand-primary: [hex из Шага 1 или #1c254f];
  --brand-secondary: [hex или #38bdf8];
  --bg: #f8f9fb;
  --surface: #ffffff;
  --text: #1a202c;
  --muted: #64748b;
  --r: 8px;
}
```

**@media print** — всегда включать:
```css
@media print {
  .vendor-card { page-break-inside: avoid; }
  body { background: white; }
  a { color: inherit; text-decoration: none; }
}
```

### Шаг 5 — Финальная проверка

Перед сдачей проверь:
- [ ] Все вендоры из scope включены
- [ ] Контакты на последней странице
- [ ] @media print работает (карточки не разрываются)
- [ ] Брендинг соответствует указанному
- [ ] Ссылки на сайты вендоров кликабельны

---

## ПРАВИЛА

- Не начинай генерацию до получения ответов на чеклист
- Если источник — только сайт без docx/PDF, сначала скрапь через `web-scraper`
- Если бренд-цвета не предоставлены — используй нейтральный корпоративный синий (#1c254f)
- Данные о вендорах — только из предоставленных источников или открытых сайтов; не выдумывай возможности продуктов
