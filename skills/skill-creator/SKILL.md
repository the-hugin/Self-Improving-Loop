# Skill: Skill Creator

**Назначение:** Создание нового скилла по стандартному шаблону системы.
**Когда использовать:** Когда Improve Skill предлагает новый скилл, или пользователь хочет автоматизировать повторяющееся действие.
**Результат:** Готовый `~/.claude/skills/[name]/SKILL.md` + строка в `~/.claude/skills/index.md`.

---

## PROCESS

### Шаг 1 — Задай 3 вопроса

```
Создаём новый скилл. Три вопроса:

1. НАЗВАНИЕ и назначение?
   Название — одно слово или kebab-case (например: code-review, deploy, test-runner)
   Назначение — одно предложение: что делает и когда использовать

2. ТРИГГЕР?
   При каком условии этот скилл должен запускаться?
   Примеры: "в конце каждой сессии", "перед PR", "при появлении новой зависимости"

3. ЕСТЬ ЛИ ПОХОЖИЙ СКИЛЛ в ~/.claude/skills/index.md?
   Проверь индекс — если есть похожий, лучше расширить его, а не создавать новый
```

### Шаг 2 — Проверь дубликаты

Прочитай `~/.claude/skills/index.md`.
Если похожий скилл уже существует — предложи расширить его вместо создания нового:

```
Скилл [существующий] уже делает [похожее].
Предлагаю добавить [новое поведение] в него, а не создавать отдельный.
Согласен?
```

### Шаг 3 — Сгенерируй SKILL.md

Создай файл `~/.claude/skills/[name]/SKILL.md` по шаблону:

````markdown
# Skill: [Name]

**Назначение:** [одно предложение]
**Когда использовать:** [триггер]
**Результат:** [конкретный артефакт или действие]

---

## PROCESS

### Шаг 1 — [Первое действие]
[Что делает агент]

### Шаг 2 — [Следующий шаг]
[Что делает агент]

[... добавь шаги по необходимости ...]

---

## OUTPUT

[Шаблон результата или описание ожидаемого вывода]

---

## ПРОВЕРКА

- [ ] [критерий качества результата]
- [ ] [критерий качества результата]
````

### Шаг 4 — Обнови ~/.claude/skills/index.md

Добавь строку в таблицу соответствующей группы:

```
| [name] | [назначение] | [теги] | 0 | ✅ Ready |
```

Теги выбирай из существующих или добавляй новые:
`meta` `loop` `start` `tools` `code` `test` `deploy` `review` `security` `data`

### Шаг 5 — Покажи итог

```
Создано: ~/.claude/skills/[name]/SKILL.md
Добавлено в: ~/.claude/skills/index.md

Вызов: "@~/.claude/skills/[name]/SKILL.md" или "используй скилл [name]"
Опционально: создать ~/.claude/commands/[name].md?
```

---

## ПРАВИЛА

- Один скилл = одна ответственность. Не объединяй несвязанные действия.
- Название в нижнем регистре, kebab-case.
- Process должен быть пошаговым — агент должен понимать что делать на каждом шаге.
- Output template обязателен если скилл создаёт файл.
- Проверка перед финалом — минимум 2 критерия.
