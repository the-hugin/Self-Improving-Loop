# Skill: extract-brand-palette

**Назначение:** Извлечение hex-цветовой палитры бренда из image-based PDF или PNG через pixel sampling (PyMuPDF). Используется как утилита внутри `doc-creator` и самостоятельно.
**Когда использовать:** Нужно получить точные цвета бренда из PDF-презентации, лендинга, логотипа или любого растрового источника — и стандартный парсинг текста ничего не даёт.
**Результат:** Список hex-значений (Primary / Secondary / Accent) + готовые CSS-переменные.

---

### Шаг 2 — Pixel sampling по ключевым зонам

Зоны для sampling (y — доля высоты страницы):

| Зона    | Y-диапазон | Что ищем |
|---------|-----------|----------|
| Header  | 0–8%      | Логотип, навбар, фоновый цвет шапки |
| Footer  | 92–100%   | Акцентная полоса, кнопки, цветной футер |
| Accent  | 45–55%    | Цветные блоки в середине слайда |

```python
import sys, fitz
from collections import Counter

sys.stdout.reconfigure(encoding='utf-8')

def sample_zone(page, y_start_pct, y_end_pct, step=5):
    """Собрать доминантные цвета в зоне страницы."""
    pix = page.get_pixmap(dpi=72)
    w, h = pix.width, pix.height
    y0 = int(h * y_start_pct)
    y1 = int(h * y_end_pct)
    counts = Counter()
    for y in range(y0, y1, step):
        for x in range(0, w, step):
            r, g, b = pix.pixel(x, y)[:3]
            # Фильтровать белый и чёрный
            if r > 240 and g > 240 and b > 240: continue
            if r < 15  and g < 15  and b < 15:  continue
            # Квантизация до шага 8 для группировки близких цветов
            key = (r // 8 * 8, g // 8 * 8, b // 8 * 8)
            counts[key] += 1
    return counts.most_common(3)

doc = fitz.open("file.pdf")
page = doc[0]  # Обложка — самый информативный слайд

zones = {
    "header": sample_zone(page, 0.00, 0.08),
    "footer": sample_zone(page, 0.92, 1.00),
    "accent": sample_zone(page, 0.45, 0.55),
}

for zone, colors in zones.items():
    print(f"\n{zone}:")
    for (r, g, b), cnt in colors:
        print(f"  #{r:02x}{g:02x}{b:02x}  (встреч: {cnt})")
```

### Шаг 3 — Интерпретация результатов

После вывода — определить роли цветов:

```
Primary   = самый частый цвет из header (фон шапки / основной бренд)
Secondary = второй по частоте из header или accent
Accent    = самый яркий/насыщенный цвет из footer (кнопки, CTA)
```

**Признаки акцентного цвета:** высокая насыщенность (один канал >> других), встречается в footer / кнопках, отличается от primary по hue.

## НЮАНСЫ И ОГРАНИЧЕНИЯ

- **Шаг sampling: 5px** — баланс скорость/точность. Уменьшить до 2 для точности, увеличить до 10 для скорости на больших файлах.
- **Квантизация // 8** — группирует близкие цвета (#1c254f и #1e274f → одна группа). Уменьшить до // 4 для большей точности различения.
- **Страница 0** — обычно обложка. Если бренд виден на другой странице — сменить индекс.
- **Несколько страниц** — для более точного результата можно усреднить по страницам 0, 1, 2 и взять самый устойчивый цвет.
- **PNG/JPG** — использовать `PIL.Image` вместо `fitz`: `img.getdata()` → тот же Counter-алгоритм.
