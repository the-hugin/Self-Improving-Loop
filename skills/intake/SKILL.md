# Skill: Intake

**Назначение:** Онбординг нового проекта — задаёт 4 вопроса и генерирует заполненный `CLAUDE.md` с Security Constraints.
**Когда использовать:** В начале каждого нового проекта, до написания любого кода.
**Результат:** Готовый `CLAUDE.md` в корне проекта. Не шаблон — конкретные данные.

---

## PROCESS

### Шаг 0 — Предложи пресет (одним сообщением, до вопросов)

```
Выбери тип проекта — это сэкономит 4 вопроса:

  1. Python CLI / Service  — скрипты, мониторинг, боты, автоматизация
  2. TypeScript / React    — веб-приложение, SPA, Next.js
  3. Electron Desktop      — десктопное приложение (React + Vite + IPC)
  4. Data Pipeline         — ETL, pandas, SQL, аналитика
  5. Вручную               — задам 4 вопроса сам
```

**Если пользователь выбрал 1–4** → используй предзаполненный пресет ниже для Tech Stack и CODE CONVENTIONS.
Задай только уточняющие вопросы: **Что строим? Что уже готово? Ограничения?**
Пресеты не освобождают от заполнения OPERATOR_TOKEN и Phase Plan — их всё равно генерируй.

**Если пользователь выбрал 5 или не ответил** → переходи к Шагу 1 (4 вопроса).

#### Пресеты Tech Stack + CONSTRAINTS

**Python CLI / Service:**
```
Language:    Python 3.11+
CLI:         typer + rich
HTTP:        requests (retry + rate-limit)
Config:      pyyaml (config.yaml + env override)
Storage:     SQLite (WAL mode) или —
Deploy:      systemd / Task Scheduler / watchdog
Naming:      snake_case / PascalCase
```

**TypeScript / React:**
```
Language:    TypeScript 5+
Framework:   React 18 + Vite
Styling:     Tailwind CSS или CSS modules
State:       Zustand / React Query (без Redux если не явно)
API:         fetch / axios
Build:       Vite + tsc --noEmit
Naming:      camelCase / PascalCase / kebab-case (files)
```

**Electron Desktop:**
```
Language:    TypeScript 5+
Shell:       Electron + React + Vite
IPC:         contextBridge + ipcMain/ipcRenderer
Packaging:   electron-builder
State:       Zustand (renderer) / main process state
Naming:      camelCase / PascalCase
```

**Data Pipeline:**
```
Language:    Python 3.11+
Data:        pandas + numpy
DB:          SQLite / PostgreSQL (psycopg2)
Analysis:    scipy / scikit-learn (если ML)
Viz:         matplotlib / plotly (опционально)
Scheduler:   APScheduler / cron
Naming:      snake_case / PascalCase
```

#### Пресеты CONSTRAINTS

**Python CLI / Service:**
```
- НЕ использовать eval() на данных из API-ответов
- НЕ хранить секреты в коде — только config.yaml + env vars
- НЕ делать синхронные HTTP-запросы без retry/timeout
- НЕ писать raw SQL вне db-модуля
```

**TypeScript / React:**
```
- НЕ хранить sensitive data в localStorage без шифрования
- НЕ использовать dangerouslySetInnerHTML без санитизации
- НЕ делать API-запросы напрямую из компонентов — только через хуки/сервисы
- НЕ коммитить .env файлы
```

**Electron Desktop:**
```
- НЕ хранить credentials в renderer process
- НЕ использовать nodeIntegration: true — только contextBridge
- НЕ выполнять shell-команды без явного подтверждения пользователя
- НЕ хранить пользовательские данные вне app.getPath('userData')
```

**Data Pipeline:**
```
- НЕ загружать весь датасет в память — использовать chunks/generators
- НЕ хардкодить пути к файлам — только через config
- НЕ запускать тяжёлые вычисления в основном потоке
- НЕ коммитить raw data файлы в репозиторий
```

---

### Шаг 1 — Задай 4 вопроса (все сразу, одним сообщением)

```
Отвечу на 4 вопроса — это займёт 2 минуты и сэкономит часы.

1. ЧТО строим?
   Одним предложением: что делает проект и для кого.
   Пример: "CLI-инструмент для автоматического ресайза изображений для веб-разработчиков"

2. СЛОЖНОСТЬ и стек?
   - Тип: [ ] Desktop  [ ] Web App  [ ] Script/Automation  [ ] Library
   - Стек (кратко): язык, фреймворк, БД если есть
   - Масштаб: [ ] Прототип (1-3 дня)  [ ] Проект (1-2 недели)  [ ] Продукт (месяц+)

3. ОГРАНИЧЕНИЯ?
   Что нельзя делать или что уже решено:
   - Нельзя менять: [зависимости / архитектуру / язык]
   - Уже решено: [какие технические решения приняты]
   - Среда: [где запускается — локально / сервер / облако]

4. ЧТО УЖЕ СДЕЛАНО?
   - Есть ли существующий код? [да/нет, краткое описание]
   - Какие файлы/компоненты уже работают?
   - Что пробовали и не сработало?
```

### Шаг 2 — Дождись ответов

Не генерируй CLAUDE.md до получения всех 4 ответов.
Если ответ неполный — уточни конкретный вопрос, не все сразу.

### Шаг 3 — Сгенерируй CLAUDE.md

Используй шаблон ниже. Заполняй **все** поля конкретными данными из ответов.
Пустых placeholder'ов быть не должно — если данных нет, пиши "не определено" или удаляй секцию.

**Обязательно:**
- SECURITY CONSTRAINTS — первой секцией, до PROJECT OVERVIEW
- OPERATOR_TOKEN — сгенерируй уникальную фразу из 4 слов (прилагательное-существительное-существительное-число)
- Phase Plan — минимум 3 фазы исходя из масштаба проекта
